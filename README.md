# AIoT Skills

华侨大学 AIoT 协会社员实用 Skill 收录与共享索引。

本仓库采用“每个 Skill 独立仓库 + 统一索引”的方式。Skill 作者维护自己的仓库，协会维护者负责审核并更新本索引。

## 提交一个 Skill

1. 在 HQU-AIoT 组织中建立公开仓库，推荐命名为 `skill-功能名称`。
2. 至少提供 `SKILL.md`、`README.md` 和 `LICENSE`。
3. 检查并移除 Token、密码、Cookie、个人信息和无权公开的第三方内容。
4. 使用 [Skill 收录申请](../../issues/new?template=skill-submission.yml) 提交仓库信息。
5. 审核通过后，维护者会将 Skill 加入本页和 `catalog.yaml`。

完整要求见 [贡献指南](CONTRIBUTING.md) 和 [Skill 规范](docs/skill-standard.md)。

## 状态说明

- **实验**：可以试用，接口或行为可能变化。
- **可用**：已完成基本测试，适合一般任务。
- **稳定**：经过持续使用和维护。
- **停止维护**：保留索引，但不建议用于新项目。

## 安全

请勿提交任何密钥、令牌、账号凭据或个人隐私。发现安全问题时，请按照 [安全说明](SECURITY.md) 联系维护者，不要在公开 Issue 中披露敏感细节。
